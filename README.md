# Salikha Photoman

Windows event photo workflow for importing JPEGs from SD cards, composing print layouts, and printing or reprinting event photos.

Download the Windows x64 installer from [Releases](https://github.com/ikykchrist/Salikha-Studio-Print-Engine/releases). Installer access and app activation use credentials issued by Salikha.

The [4×6 operator manual](docs/Salikha%20Photoman%20System%20Manual%204x6.pdf) covers event setup, SD import, and printing.

## Build on Windows

Install Python, Microsoft C++ Build Tools, and Inno Setup 6. Set the SALIKHA_INSTALLER_PASSWORD environment variable in your current shell, then run build.bat. The build writes the installer to installer/.
